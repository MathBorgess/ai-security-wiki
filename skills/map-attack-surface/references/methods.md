# Methods and decisions

Source IDs resolve in [sources](sources.md). **Documented** identifies the upstream practice; **adaptation** identifies this project's operational rule. Every action here uses supplied evidence and produces a plan; upstream commands are not executed.

## Tool selection without execution

Tools answer narrower questions than their marketing descriptions. A saved JavaScript parser can suggest endpoints; a network scraper sends requests; an LLM generator sends input to a model provider; an evaluation target can invoke a real application. State those data flows, pin the version and review dependencies before recommending a future experiment. No tool installation, credentials, scanning or provider call is part of this skill.

CSPReconGO is a useful source-review exercise: the inspected code matches header names containing `csp`, which does not match the standard `Content-Security-Policy` name. Its README also marks cross-run tracking as TODO (JH5). Do not present that snapshot as a verified CSP inventory tool.
