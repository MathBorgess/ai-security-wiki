# DASF-R-13.11 — Unexpected RCE and Code Attacks

Source: [official compendium, AI Lifecycle Risks, row 75](https://docs.google.com/spreadsheets/d/1lD5nKC1QNoUTDXdMp31NA9eKcUYGjhtC34MCfQpqpGo/edit#gid=307775890&range=A75:AE75). Snapshot: 2026-10-22; source revision: DASF v 3.0.

## Risk mechanism

Attackers exploit AI-generated execution environments to inject malicious code, trigger unintended system behaviors, or execute unauthorized scripts.

## Source control guidance

• DASF 34: Run models in multiple layers of isolation with unprivileged VMs and network segregation. Protects back-end internal systems from LLM access. The most reliable mitigation is to always treat all LLM and agent output as potentially malicious — an untrusted entity has been able to inject text as user input. Restrict AI code generation permissions, sandbox execution environments, and monitor AI-generated scripts before and during execution.
• DASF 38: Platform security — penetration testing, red teaming, bug bounty, and vulnerability management. Conduct regular sandbox breakout testing to validate that AI code execution environments are properly hardened and that RCE vulnerabilities cannot be chained to escape the execution boundary.
• DASF 55: Monitor audit logs to detect unusual code execution patterns, unauthorized script launches, and anomalous system calls that may indicate successful or attempted RCE
• DASF 56: Restrict outbound connections from models to prevent AI-generated code — if executed — from phoning home, establishing reverse shells, or exfiltrating data to attacker-controlled endpoints
• DASF 62: Implement network segmentation to isolate AI code execution environments from sensitive internal systems, limiting the lateral movement capability of any successfully executed malicious code
• DASF 63: Update software to patch AI code execution environments, sandboxes, and container runtimes. Unpatched execution environments provide footholds for privilege escalation and sandbox escape.
• DASF 64: Limit access from AI models and agents, applying least privilege to execution environments so that even successfully executed malicious code has constrained access to system resources and data
• DASF 71: Log and register AI agents to maintain traceability of which agent generated and executed code, enabling attribution and forensic analysis following an RCE incident
