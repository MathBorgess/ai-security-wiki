# DASF-R-13.35 — Update and Patch Management

Source: [official compendium, AI Lifecycle Risks, row 99](https://docs.google.com/spreadsheets/d/1lD5nKC1QNoUTDXdMp31NA9eKcUYGjhtC34MCfQpqpGo/edit#gid=307775890&range=A99:AE99). Snapshot: 2026-10-22; source revision: DASF v 3.0.

## Risk mechanism

Update and patch management issues involve insecure update mechanisms or delayed application of security patches. This includes unverified updates, delayed patches, insecure update channels, and inadequate update verification. Clients with poor update mechanisms remain vulnerable to known security issues.

## Source control guidance

• DASF 38: Platform security — penetration testing, red teaming, bug bounty and vulnerability management — maintain an active vulnerability management program for MCP client software. Track CVEs affecting MCP client dependencies  and prioritize patching based on exploitability and impact.
• DASF 53: Third-party library control — govern the update and verification of third-party MCP client libraries and dependencies. Validate the integrity and authenticity of updates before applying them. Monitor for abandoned or unmaintained libraries that will no longer receive security patches.
• DASF 55: Monitor audit logs — detect exploitation attempts targeting known unpatched vulnerabilities in MCP client software. Anomalous behavior patterns may indicate a known vulnerability is being actively exploited, signaling urgent patch deployment.
• DASF 63: Update software — patch and update MCP client software and all dependencies regularly to address known vulnerabilities. In Databricks, automatic cluster updates ensure OS images and security patches are applied
  periodically. Establish a patch cadence and SLA for critical security updates to MCP client components.
• DASF 68: Use Securely Hosted Managed MCP Servers — Databricks managed MCP servers are maintained and patched by Databricks, removing the operational burden of server-side patch management and ensuring clients always connect to up-to-date server software.
• DASF 69: Securely host Custom MCP Servers — deploy custom MCP servers as Databricks Apps to benefit from platform-level updates and security patches applied by Databricks, reducing the risk of running unpatched custom server software.
