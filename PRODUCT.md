# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML on GitHub Pages, generated from the existing Markdown wiki. Selected by the owner on 2026-10-22. The local Node.js MCP remains a separate stdio process.

## Users

Developers assessing the security of ML, GenAI and agentic systems, and agents retrieving a source-backed defensive method on their behalf.

## Product Purpose

Make DASF knowledge easier to discover, investigate and apply. The owner wants this independent public contribution to demonstrate curiosity about AI security and protection at scale. Publication alone does not establish adoption or professional outcomes.

## Positioning

A source-traceable DASF 3.0 wiki, versioned catalog and defensive MCP: classify the whole system, select risks and controls, investigate evidence, propose corrections, retest and explain. Preserve source inconsistencies rather than hiding them.

## Capabilities and Constraints

The public snapshot contains 97 risks, 73 controls, 13 components and seven deployment patterns. HTML and Markdown must share the same content. The website must remain readable without JavaScript. No target assessment data, credentials, tracking scripts or remotely exposed MCP are part of this documentation surface.

## Evidence on Hand

The catalog, dated source register, executable MCP checks and synthetic tenant-isolation example are available in this repository. Independent skill evaluation, universal host compatibility, search rankings and community adoption are not established.

## Product Principles

- Start with the developer's system and evidence.
- Make the source and the project's interpretation distinguishable.
- Keep plain text available to humans and agents.
- Explain what a test actually proves.

## Confirmed Surface Priority

Owner decision, 2026-10-22: exploring risks and the audit workflow is the primary route; MCP installation sits alongside it.
